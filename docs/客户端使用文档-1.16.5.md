# Keran 反作弊体系 v6 — 整合版

> 本文档覆盖：**KeranAntiCheat 2.0.0**（服务端反作弊插件，整合版）+ **KeranClient 1.1.0**（Fabric 1.16.5 客户端检测 mod）。
> 服务端**两个插件已整合为一个** `KeranAntiCheat-2.0.0.jar`；全部改动已在本机 Paper 1.16.5 + 模拟 Fabric 客户端实测通过。

## 一、本次改动（v6 — 整合版）

### 1. 服务端插件整合（两个 → 一个）
- **KeranAntiCheat + KeranClientBridge 合并为单一插件** `KeranAntiCheat-2.0.0.jar`
- 只需装**一个 jar**：反作弊检测（19 个检测器）+ 客户端桥接（强制门槛/指纹上报/MD5 严格校验）全部内置
- **命令统一**：全部通过 `/kac`（旧 `/kacc` 作为别名仍可用）
  - 反作弊：`/kac help` `alerts` `info` `reset` `checks` `toggle` `stats` `ban` `unban` `kick` `verbose` `reload`
  - 客户端桥接：`/kac cinfo <玩家>`（指纹摘要）`/kac detail <玩家>`（详细清单）`/kac modsmd5 <玩家>`（mods MD5）`/kac packsmd5 <玩家>`（材质包 MD5）`/kac list`
- **权限统一**：`kac.admin`（管理）`kac.notify`（告警）`kac.bypass`（豁免+门槛）；旧 `kacc.*` 权限保留兼容

### 2. 提示前缀统一 [KAC]
- 所有指令反馈前缀统一为 **`§8[§cKAC§8]`**，例如 `/kac reload` → `[KAC] 配置已重载`
- 踢出/封禁消息前缀统一 `[KAC]`

- 服务端插件：`2.0.0`（整合大版本）

### 继承自 v5 的功能（全部保留）
- 客户端启动预计算 mods/材质包目录 MD5，进服自动上报（含文件名+大小+MD5+目录 MD5）
- MD5 严格校验开关 `strict-md5`（默认关，开启后必须与 config 完全一致否则踢出）
- 强制安装门槛（5 秒内未上报/未注册频道即踢）
- 客户端检测强制开启（不可关闭）
- 提示文本可自定义（`messages-bridge` 段，支持占位符）

## 三、服务端安装与配置

1. 删除旧插件 `KeranClientBridge-1.0.0.jar`（如有），放入 `KeranAntiCheat-2.0.0.jar` 到 `plugins/`，重启
2. 生成 `plugins/KeranAntiCheat/config.yml`（自动包含反作弊 + 桥接全部配置段）

```yaml
# 反作弊检测(原有 19 检测器)……
# 桥接配置：
join:
  enabled: true          # 强制安装门槛
  wait-seconds: 5        # 超时秒数
  kick-if-no-client: true
strict-md5:
  enabled: false         # MD5 严格校验默认关闭
  mods-dir-md5: ""       # 期望 mods 目录整体 MD5
  packs-dir-md5: ""      # 期望材质包目录整体 MD5
messages-bridge:         # 提示文本(可自定义, 支持 %player% %details% %seconds% 等)
  join-no-client: "§e[KAC] §e%player% §7未安装 KeranClient 客户端"
  blacklist-hit: "§c[KAC] §e%player% §c检测到作弊模组: §f%details%"
  # ...其余见 config.yml
```

## 四、客户端安装

1. Fabric 1.16.5 客户端，`KeranClient-1.1.0.jar` 放入 `.minecraft/mods/`
2. 首次运行生成 `.minecraft/config/kacclient.json`（检测强制开启，不可关闭）
3. 进服自动上报指纹 + 两目录 MD5；客户端命令 `/kacclient status|report|reload`

## 五、管理员常用操作

| 命令 | 作用 |
|---|---|
| `/kac info <玩家>` | 反作弊违规记录 |
| `/kac cinfo <玩家>` | 客户端指纹摘要 |
| `/kac detail <玩家>` | 客户端详细 mods/材质包清单（含文件大小） |
| `/kac modsmd5 <玩家>` | mods 目录文件 MD5 |
| `/kac packsmd5 <玩家>` | 材质包目录文件 MD5 |
| `/kac list` | 已上报客户端玩家列表 |
| `/kac checks` / `toggle` | 检测器状态/开关 |
| `/kac ban/unban/kick` | 处罚管理 |
| `/kac reload` | 重载配置 |
| `/kacc ...` | 旧命令别名，等效 `/kac` |

## 六、已知边界

- XRay/KillAura 为事件级检测，有精度上限；FreeCam 等需 ProtocolLib 包层检测（未实现）
- 客户端 mod 是"自证清白+特征发现"，玩家删 mod 可绕过——但服务端心跳超时会提示，且强制门槛保证进服必须有客户端
