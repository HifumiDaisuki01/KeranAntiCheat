# Keran Anti Cheat v1.0.0

适用于 **Paper 1.16.5 枪械 PVP + PVE 刷怪服** 的反作弊插件。

- 命令前缀：`/kac`
- 作者：Keran Technology Co., Ltd.
- 共 **19 个检测器**，覆盖移动、战斗、世界交互三大类
- 内置违规值(vl)阶梯处罚：告警 → 踢出 → 封禁（可配置、可单独开关）

---

## 一、安装

1. 将 `KeranAntiCheat-1.0.0.jar` 放入服务器 `plugins/` 目录
2. 重启服务器（或 `/reload`）
3. 首次启动自动生成 `plugins/KeranAntiCheat/config.yml`，按需调整后 `/kac reload` 生效

> 运行环境：Paper/Spigot 1.16.5，Java 8/11/16 均可。依赖仅 spigot-api，无第三方前置插件。

## 二、命令（全部以 /kac 开头）

| 命令 | 说明 | 权限 |
|---|---|---|
| `/kac help` | 帮助 | kac.admin |
| `/kac alerts [on\|off]` | 切换本人告警接收（适合挂机观察的管理员） | 玩家自用 |
| `/kac info <玩家>` | 查看玩家违规记录（在线/离线均可） | kac.admin |
| `/kac reset <玩家>` | 清零违规记录 | kac.admin |
| `/kac checks` | 列出全部检测器及当前开关状态 | kac.admin |
| `/kac toggle <检测器> [on\|off]` | 运行时开关检测器（重启后按配置恢复） | kac.admin |
| `/kac stats` | 全局违规统计 | kac.admin |
| `/kac ban <玩家> [小时] [原因]` | 封禁（0 小时 = 永久） | kac.admin |
| `/kac unban <玩家>` | 解封 | kac.admin |
| `/kac kick <玩家> [原因]` | 踢出 | kac.admin |
| `/kac verbose [on\|off]` | 详细日志（排查误报用） | kac.admin |
| `/kac reload` | 重载配置 | kac.admin |

## 三、权限

| 权限 | 说明 | 默认 |
|---|---|---|
| `kac.admin` | 全部管理命令 | op |
| `kac.notify` | 接收反作弊告警 | op |
| `kac.bypass` | 完全豁免所有检测 | 无 |
| `kac.bypass.<检测器id>` | 单独豁免某检测（如 `kac.bypass.fly`） | 无 |

> 配置里还有两个硬性豁免开关：`settings.bypass-op`（OP 豁免，默认开）、`settings.bypass-admin`（管理员豁免，默认开）。

## 四、检测器一览（19 个）

### 移动类
| 检测器 id | 名称 | 检测原理 |
|---|---|---|
| `fly` | 飞行 | 持续上升超过跳跃极限 / 空中悬浮过久，豁免液体、攀爬、鞘翅、击退 |
| `speed` | 速度 | 地面/空中水平速度超限，自动计算速度药水加成，豁免冰面滑行 |
| `timer` | 加速 | 每秒移动包数量超限（正常约 20/s） |
| `nofall` | 摔落 | 下落超 3 格却从未受到摔落伤害 |
| `jesus` | 水上行走 | 深水区垂直位移≈0 悬浮过久 |
| `spider` | 爬墙 | 贴墙持续上升且净高超过跳跃极限 |
| `blink` | 瞬移 | 单次移动位移超 2.5 格 |
| `elytra` | 鞘翅 | 鞘翅滑翔水平速度超限 |

### 战斗类
| 检测器 id | 名称 | 检测原理 |
|---|---|---|
| `killaura` | 自瞄 | ① 同 tick 攻击多个目标 ② 攻击方向与视线夹角过大（视野外攻击） |
| `aim` | 视角 | 单 tick / 双 tick 旋转速度异常（瞄准机器） |
| `reach` | 距离 | 近战攻击 3D 距离超限 |
| `criticals` | 暴击 | 站立状态却上报"在空中"（伪造落地触发暴击） |
| `autoclicker` | 连点 | 每秒左键点击超限（**默认关闭**，见下方调优） |
| `velocity` | 击退 | 受击后 3 tick 内水平位移过小（防击退） |

### 世界/交互类
| 检测器 id | 名称 | 检测原理 |
|---|---|---|
| `xray` | 透视 | 挖掘统计：矿物占比超限（启发式，配合人工复核） |
| `nuker` | 范围挖掘 | 同 tick 破坏相距 4 格以上的多个方块 |
| `scaffold` | 搭路 | 每秒放置方块超限（搭路机/塔楼） |
| `fastuse` | 速用 | 每秒食用物品超限 |
| `chat` | 刷屏 | 每秒聊天超限，自动禁言 10 秒 |

## 五、枪械服调优建议（重点）

枪械插件（CrackShot / WeaponMechanics 等）与反作弊天然存在冲突，本插件已内置针对性豁免，建议按实际枪械插件再微调：

| 场景 | 建议 |
|---|---|
| **枪械后坐力 / 枪伤击退** | 保持 `settings.velocity-exempt-ticks: 12`（受击后 12 tick 豁免移动检测）。若你的枪械击退很强，调到 15-20 |
| **枪械连发点击** | `autoclicker` 默认**关闭**。若开启，把 `max-cps` 调到你的枪械实际点击需求（如 25） |
| **范围伤害 / 爆炸枪械** | 若一枪命中多目标被 `killaura` 误报：把 `max-targets-per-tick` 调大或设 0 关闭多目标检测；`max-angle` 保持 60 一般安全 |
| **枪械近战刀/长武器** | `reach.max-reach` 默认 4.0，若枪械插件近战距离更大请调大或设 0 关闭 |
| **PVE 高频砍怪** | `autoclicker` 不建议开；`velocity` 在盾牌格挡时会自动豁免 |
| **挖矿/矿物礼包插件** | 若配合连锁挖矿或矿物礼包，`xray.max-ore-ratio` 可能需要调高（0.5）或关闭 |
| **PVP 高机动道具** | 若服里有速度道具，调大 `speed.max-ground-speed`（疾跑 0.28，速度 II 约 0.39，默认 0.65 已留余量） |

**通用排误流程**：开着 `/kac verbose` 观察 → 误报的检测用 `/kac toggle <检测器> off` 临时关 → 改配置阈值 → `/kac reload`。

## 六、处罚机制

每个检测独立累计违规值 vl：

- 每次触发 +1 vl，达到 `punishments.default-kick-vl`（默认 20）→ **踢出**
- 达到 `punishments.default-ban-vl`（默认 40）→ **封禁（永久）**
- 可在各检测下用 `kick-vl` / `ban-vl` 单独覆盖；`0` = 不自动处罚，只告警
- 当前配置默认所有检测 `kick-vl/ban-vl = 0`，即**只告警不处罚**，稳定运行后再逐步放开

## 七、数据文件

```
plugins/KeranAntiCheat/
├── config.yml          # 主配置
└── data/
    ├── vl.yml          # 玩家违规记录(自动保存, 重启保留)
    └── bans.yml        # 封禁名单(登录时自动拦截, 到期自动解封)
```

## 八、已知边界（如实说明）

- **透视(XRay)** 是启发式统计，无法 100% 精确，靠矿物占比异常报警 + 管理员复核；数据有 `reset-after` 防稀释机制
- **FreeCam / 反恐精英视角**类作弊需要数据包层检测（ProtocolLib/PacketEvents），本插件为无依赖纯事件实现，暂不覆盖；`aim` + `fly` + `blink` 组合可侧面限制
- **KillAura** 对"攻击角度"的检测仅针对近战（damager 为玩家本体），枪械弹射物不参与，这是刻意为枪械服规避误报的设计
- 若服务器使用**多世界/领地/商店/方块菜单**等插件大量模拟破坏/放置事件，请按需调整 `nuker`/`scaffold` 阈值

## 九、源码构建（可选）

```bash
mvn -s mvn-settings.xml clean package   # 产出 target/KeranAntiCheat-1.0.0.jar
```

项目结构：`check/movement`（8 个移动检测）、`check/combat`（6 个战斗检测）、`check/world`（5 个世界检测），新增检测只需继承 `Check` 并注册到 `CheckManager.registerChecks()`。
