## 三、安装步骤

### 服务端
1. 将 `KeranAntiCheat-3.0.0.jar` 放入服务端 `plugins/` 目录
2. 启动服务器，插件自动生成 `plugins/KeranAntiCheat/config.yml`
3. 按需修改配置，执行 `/kac reload` 热重载（无需重启）

### 客户端
1. 安装 Fabric Loader（选择 1.20.1）
2. 将 `KeranClient-2.0.0.jar` 与 **Fabric API** 一同放入 `mods/` 目录
3. 启动游戏，进服后自动上报指纹

> **注意**：客户端模组为**强制开启**设计，玩家无法关闭——这是防作弊的前提。

## 四、本次升级的核心改动

### 4.1 引擎重构：从"单次即罚"到"证据累积"

老模型（v2.0）误报严重的根因是**五重缺陷叠加**：

| 老模型缺陷 | 后果 | v3.0 修复方案 |
|---|---|---|
| 超过阈值一次即计违规 | 瞬态网络抖动直接触发告警 | **连续帧验证**（`min-consecutive`）：需连续 N 次异常才计入 |
| 无置信度概念 | 一次异常与十次异常等价 | **证据累积**（`alert-threshold`）：异常累加证据分，达标才告警 |
| 违规值只增不减 | 偶发误报永久累积，最终误封 | **VL 时间衰减**（`vl-decay-per-10s`）：每 10 秒削减 VL |
| 无延迟补偿 | 高 Ping 玩家被误判 | **延迟补偿**（`lag-compensation-ratio`）：按 Ping 动态放宽阈值 |
| 豁免矩阵不全 | 冰面/气泡柱/细雪等场景必误报 | 补齐 **1.20.1 全部新机制豁免** |

**核心调参思路**：某个检测误报时，**优先调大 `min-consecutive` 与 `alert-threshold`，而不是直接关掉检测**。这样既能保持检出率，又能压掉误报。

### 4.2 检测条目：19 项 → 28 项

新增 9 个检测器：

| 分类 | 新增检测器 | 说明 |
|---|---|---|
| 移动 | `NoSlow` | 使用物品时未减速（进食/拉弓加速） |
| 移动 | `Step` | 异常台阶攀爬高度 |
| 移动 | `GroundSpoof` | 伪造 onGround 状态 |
| 战斗 | `AntiKb` | 击退抵抗/无击退 |
| 战斗 | `Hitbox` | 命中箱膨胀 |
| 战斗 | `AutoBlock` | 攻击同时格挡 |
| 战斗 | `Backtrack` | 攻击历史位置实体 |
| 世界 | `FastBreak` | 超出工具能力的破坏速度 |
| 世界 | `Inventory` | 异常背包操作/自动换装 |

### 4.3 关键检测器算法改进

**自瞄检测（AimCheck）**
- 老版：仅比对 tick 间旋转角度 → 枪械服几乎不可用
- 新版：**GCD 灵敏度网格一致性分析** + **旋转平滑度（变异系数）分析**
  - 人类鼠标移动受 DPI 限制，旋转量必为 GCD 的整数倍；自瞄常破坏此规律
  - 自瞄的旋转曲线过于平滑，而人类必然抖动

**连点器检测（AutoClickerCheck）**
- 老版：单纯数 CPS（`CPS > 18` 即判违规）→ 误伤 Butterfly/Drag Click 玩家
- 新版：**点击间隔方差分析**（核心判据）+ CPS 硬上限（辅助）
  - 连点器/宏的间隔**变异系数 < 0.045**（近乎恒定）
  - 人类手点通常 **CV > 0.15**
  - 自动武器虽快，但受后坐力/节奏影响仍有抖动，不会误判

**距离检测（ReachCheck）**
- 新版采用**延迟 + 目标移动 + 武器附加射程**三重补偿

**透视检测（XRayCheck）**
- 新增强特征：**"未经石层直取珍贵矿物"**（`oresWithoutStone`）

**飞行检测（FlyCheck）**
- 严格化 `pureHover` 判定：需垂直+水平位移都≈0，且不贴墙、不在边缘、无支撑

## 七、误报调优指引

如果某个检测出现误报，按以下顺序调整（配置文件 `settings` 与 `checks.<检测器>` 段）：

1. **调大 `min-consecutive`**（如 3 → 5）：需要更多连续异常才计入
2. **调大 `alert-threshold`**（如 2.0 → 3.5）：需要更多证据才告警
3. **调大 `evidence-decay-rate`**：正常观测更快削减证据
4. **调大 `lag-compensation-ratio`**：高 Ping 环境放宽更多
5. **实在无法调和的极端场景**，再用 `/kac toggle <检测器> off` 关闭单项

> **不推荐**直接关闭检测——枪械 PVP 服的作弊者会立刻利用空档。
